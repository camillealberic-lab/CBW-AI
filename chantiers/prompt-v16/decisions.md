# Décisions de Camille — prompt v1.6 (niveau standard)

- Camille reste en **standard** : c'est ce niveau qu'on améliore (le léger ne bouge pas).
- Standard = **entre-deux** : reformulation **très légère**, uniquement pour aider à la compréhension. Pas de réécriture « plus plus plus ».
- Mot inexact / mot cherché (« le truc pour… », mauvais mot) : **reformuler la phrase avec le bon mot**.
- Oral familier → **écrit correct** : « je sais pas » → « je ne sais pas », « t'es » → « tu es », « y a » → « il y a » (règle 3 actuelle conservée sur ce point).
- Sortie fidèle : ses mots, ses tournures, ses nuances ; pas de mise en forme non demandée (paragraphes / listes) à confirmer avec la veille.
